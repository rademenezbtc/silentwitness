# Security

## Bugs in a signer found with SilentWitness

Follow [docs/disclosure-policy.md](docs/disclosure-policy.md). In short:
released firmware that can lose or lock funds is reported privately to the
signer project first.

## Bugs in SilentWitness itself

If SilentWitness gives a wrong verdict, use a normal issue.

If you find something that could harm people running it (for example a way for
a crafted vector or a simulator to reach the operator's machine), report it
privately through GitHub's **Report a vulnerability** button on this
repository's Security tab.
